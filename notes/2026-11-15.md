### 案例 02 · 删除后空间不释放

| 阶段 | 变化 |
|---|---|
| 基线 | — |
| 写 5G 文件 | +5G |
| `rm` 之后 | **+5G 仍在（没回来）** |
| 杀掉持有进程 | 回落 |

**决定性证据**：

```text
COMMAND  PID  USER      FD TYPE DEVICE SIZE/OFF NLINK NODE NAME
tail     5072 <user>     3r REG  8,48   5368709120    0 59388 /tmp/held.log (deleted)
```

**根因**：`rm` 只删目录项，inode 的 `i_nlink` 归零，但只要还有进程打开（`i_count > 0`），数据块就不释放。

**为什么 `du` 看不到、`df` 看得到**：`du` 沿目录树统计，文件已经不在目录里；`df` 看文件系统块分配。

## 四、Shell 入门（约 1 小时）

| 概念 | 写法 | 用途 |
|---|---|---|
| 变量 | `NAME="小明"` / `echo "$NAME"` | 存值，改一处全变 |
| 判断 | `if [ "$AGE" -ge 18 ]; then ... fi` | 让脚本做决定 |
| 循环 | `for dir in /tmp /var; do ... done` | 一次处理多个 |
| 函数 | `show_size() { local d="$1"; ... }` | 打包重复逻辑 |
| 命令替换 | `size=$(du -sh "$1")` | 把命令输出存进变量 |
| 默认值 | `${1:-/}` | 没传参数就用默认 |
| 局部变量 | `local size` | 防止变量污染 |

**数字比较**：`-gt` 大 / `-ge` 大于等于 / `-lt` 小 / `-le` 小于等于 / `-eq` 等 / `-ne` 不等

## 七、今天踩的坑（**这部分最值钱**）

### 1. shell 少了 7 个空格

```bash
[-n "$X" ]        →  [ -n "$X" ]
{printf ...}      →  { printf ...; }
printf'%s'        →  printf '%s'
```

**规则**：`[` `]` `{` `}` 前后、命令与参数之间要空格；变量赋值 `=` 两边**不要**空格。

### 2. `du -sh /` 卡住不出输出

**原因**：WSL 的 `/` 下面挂着 Windows 的盘，等于把整个宿主机扫一遍。
**修法**：加 `-x` 不跨文件系统；用 `timeout 5` 兜底；**先打印再计算**，让人看到进度。

### 3. 命令行四层引号嵌套

PowerShell → wsl → bash -lc → bash -c，必炸。
**规矩：超过两层引号就写成文件。**

### 4. 两个 git add 忘了中间 commit

**修法**：`git restore --staged <目录>` 把一组拿回工作区，再分开提交。
**这正是 Lab 03 场景 B。**

### 5. 云主机忘记关停

开机后几天没停，产生了额外费用，白烧额度。
**教训**：用完立刻停，选「节省停机模式」；没把握就在日历上设提醒。
